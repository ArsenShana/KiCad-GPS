# GPS Tracker — демонстрационный прототип

Открыть симуляцию: `python3 server.py`, затем http://127.0.0.1:8765 . Презентация: http://127.0.0.1:8765/presentation.html .

Сборка ядра на macOS: `clang++ -std=c++17 -dynamiclib firmware/tracker.cpp -o firmware/libtracker.dylib`.
Проверка: `python3 firmware/test_core.py`.

KiCad: hardware/GPS-Tracker.kicad_pro. Плата — 70 × 45 мм, блоковая компоновка с условными габаритами модулей. Отсутствуют электрические соединения и реальные посадочные места; изготовление по этим файлам недопустимо. Схема — функциональная, а не электрическая.

Результат: работающая локальная симуляция исполняет C++ ядро; 3D модель компоновки, схема обмена, протокол, презентация. Не реализованы физические UART/BLE/LTE драйверы, загрузочный образ, телефонное приложение и production сервер. Локальный сервер обслуживает симуляцию, не является сервером приёма реальных устройств. Модель не оценивает RF, точность GPS, энергопотребление или срок работы батареи.

До выпуска: согласовать операторов/страны, наличие LTE-M/NB-IoT, GNSS выбранного варианта BG95, eUICC и профили оператора, размеры, аккумулятор и срок работы, сервер и приложение Android/iOS. eSIM не создаёт покрытие; телефон помогает только при собственном интернете. См. docs/architecture.md.
