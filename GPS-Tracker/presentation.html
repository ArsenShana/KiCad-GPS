GPS Tracker

Координаты через LTE и резервный канал телефона

GNSS · eSIM · Bluetooth · сервер

02 / 08

Как движутся данные

GNSS → контроллер → модем → сервер

Если сотовая сеть недоступна: контроллер → BLE → телефон → интернет → сервер. У телефона должен быть собственный доступ в интернет.

03 / 08

Устройство

nRF52840 + модем семейства BG95 + eUICC

Аккумулятор, защита и зарядка, питание модема и MCU, согласование UART, отдельные LTE/GNSS/BLE антенны. Вариант модема и оператор уточняются.

04 / 08

Надёжная доставка

Храним точку до подтверждения сервера

Стабильный идентификатор позволяет повторять отправку. Сервер удаляет дубликаты. Для устройства нужен журнал flash; демонстрация использует очередь RAM на 256 точек.

05 / 08

Демонстрация

Отключаем LTE → работает телефон

Отключаем интернет телефона → очередь растёт. Возвращаем сеть и отключаем новые измерения GNSS → очередь выгружается. Отключаем ACK → точка сохраняется для повтора.

06 / 08

Прошивка

Работающее C++ ядро выбора канала

Локальная симуляция вызывает скомпилированное ядро. Проверены LTE, телефон, offline, ACK, переполнение и выгрузка. UART/AT/BLE, flash, TLS и бинарный образ для устройства ещё требуют реализации.

07 / 08

Модель и KiCad

Плата-концепт 70 × 45 мм

Есть функциональная схема, блоковая компоновка и OBJ модель. Нет электрической схемы, трассировки, RF-расчётов и проверенных посадочных мест. Это не производственные файлы.
